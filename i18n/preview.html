实现要点

  • 使用 vue-i18n@11.4.23；英文原文直接作为 key，fallbackLocale 为 en，未翻译项自动回退英文。
  • 默认语言读取 localStorage，其次 navigator.language，最后回退 en；切换后同步写入 html lang。
  • 模板使用 $t()，脚本使用全局 t()；Vuelidate 的校验消息通过 helpers.withMessage 接入翻译。
  • 测试环境强制英文，原有英文断言无需改动；另有 i18n-full.test.ts 校验中文输出与语言切换。
  • 提供 check-i18n.mjs 与 check-hardcoded.mjs；上游更新后主要维护 JSON 词条并运行检查脚本。
  • 不在本次范围：语音提示音频、Go 后端错误文案、doc/ 文档站。
